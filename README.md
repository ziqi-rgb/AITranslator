# AITranslator

#### 介绍
使用大语言模型来翻译文件的图形化UI软件，目前支持以下类型文件的翻译
1. MTool导出的json格式的待翻译文件
2. Translator++导出的包含csv文件的文件夹
3. srt字幕文件
4. txt文本文件

#### 使用说明
1.  打开此软件
2.  使用内置加载器加载GGUF模型 Or 设置好OpenAI接口参数
3.  新建翻译任务
4.  配置翻译任务的翻译选项
5.  开始翻译，并等待任务完成
6.  如果存在翻译失败的文本，请手动翻译失败部分，并合并翻译结果

#### 文件夹分组与批量导入
1. **多级分组**：未完成视图与已完成视图左侧均提供分组导航树（TreeView），两个视图共享同一棵分组树，可将任务组织为任意层级的分组。点击分组即可在右侧过滤显示该视图下该分组（含子分组）的任务；未归入任何分组的任务显示在固定的"未分组"节点下。支持新建、重命名、删除分组（删除后组内任务回落到"未分组"）。任务翻译完成后移至已完成视图，但仍保留在原分组中，切换视图即可按同一分组浏览。
2. **批量导入文件夹**：在"添加任务"菜单中选择"批量导入"（或直接拖入文件夹、选择"文件夹"），选定一个文件夹后，程序会递归扫描其所有子文件夹中指定格式的文件（csv / json / srt / txt，仅一种格式时自动选定，多种时弹窗选择），并**按目录层级自动生成分组树**——所选文件夹自身名称作为顶级分组，其下同一子文件夹的文件归入同一子分组，完整保留原始目录结构。
3. **格式选择**：导入文件夹时若同时存在多种受支持格式，由用户弹窗选择要导入的格式（避免同目录下源文件与配置文件如 .txt 与 .json 造成误导入）；仅一种格式时自动选定，不弹窗。
4. **兼容性**：已有的旧任务在首次启动时自动归入"未分组"，无需手动迁移；分组关系保存在 `翻译数据/分组.json`，不影响各任务目录本身的结构。
5. **按分组导出翻译结果**：在任一分组树（未完成或已完成视图）上右键任意分组，选择"导出翻译结果…"，选定目标目录后，程序会**按分组树结构原样还原目录层级**（被点击的分组自身名称作为顶层文件夹），将该分组及所有子分组中各任务的翻译结果（合并后的最终文件）导出到对应子目录下。导出的文件名沿用原始导入文件的名称与扩展名；仅导出翻译结果，不含源文件、配置等其它文件。注意：任务需已完成合并才会存在可导出的结果文件，未合并的任务会被跳过并在完成提示中计数说明。
6. **已完成视图分组**：已完成视图与未完成视图共用同一套分组结构（分组树、命名、层级完全一致），左侧分组栏同样支持新建 / 重命名 / 删除分组与右键导出。分组归属与任务完成状态无关，因此任务从"未完成"变为"已完成"后不会丢失其所在分组。
7. **自动创建分组的空组提示**：导入文件夹时按目录结构自动创建的分组（手动新建的分组不受影响）在其中的任务被删除、且该分组已无任务时，会弹窗询问是否删除该分组（含其子分组与内容）。
8. **删除分组与内容**：分组右键菜单提供"删除分组与内容"，可一次性删除该分组及其所有子分组下的全部任务，并清除磁盘上的翻译数据，操作不可恢复（会二次确认）。
